Les stratégies globales : spécialisation ou diversification

Management · Première STMG · Thème 3 - Les choix stratégiques des organisations

Les notions clés

Spécialisation
se concentrer sur un seul métier / marché pour y devenir performant
Diversification
se développer sur de nouveaux métiers ou marchés pour répartir les risques et saisir des opportunités

À l’échelle de toute l’organisation, deux grandes orientations :

  • Spécialisation : se concentrer sur un seul métier / marché pour y devenir performant.
  • Diversification : se développer sur de nouveaux métiers ou marchés pour répartir les risques et saisir des opportunités.

Un DAS (Domaine d’Activité Stratégique) est un sous-ensemble homogène d’activités pour lequel on peut définir une stratégie propre.
