Méthode - construire un commentaire

Français (EAF) · Première STMG · Méthode - Le commentaire littéraire

Les notions clés

Bâtir un plan
2 ou 3 axes de lecture (ex. « un portrait élogieux » / « une critique voilée »)
Rédiger
chaque paragraphe = une idée + une citation + une analyse
  • Lire et repérer les mouvements du texte (ses grandes étapes de sens).
  • Analyser les procédés (figures, ponctuation, champs lexicaux) → toujours dire quel effet ils produisent.
  • Bâtir un plan : 2 ou 3 axes de lecture (ex. « un portrait élogieux » / « une critique voilée »).
  • Rédiger : chaque paragraphe = une idée + une citation + une analyse.

Erreur à éviter

Ne pas paraphraser (redire le texte). Le commentaire explique comment le texte produit du sens.
