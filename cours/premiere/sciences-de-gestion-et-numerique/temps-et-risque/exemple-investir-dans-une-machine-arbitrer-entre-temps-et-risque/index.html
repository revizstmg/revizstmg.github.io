Exemple - investir dans une machine : arbitrer entre temps et risque

Sciences de gestion et numérique · Première STMG · Thème 4 - Temps et risque

Les notions clés

Le temps
un investissement engage l’avenir ; le gain est différé, pas immédiat
Le risque
la machine peut tomber en panne, la demande peut baisser → le résultat est incertain

Cas

Une entreprise investit 50 000 € dans une machine qui doit rapporter davantage… mais seulement dans quelques années.

  • Le temps : un investissement engage l’avenir ; le gain est différé, pas immédiat.
  • Le risque : la machine peut tomber en panne, la demande peut baisser → le résultat est incertain.
  • Décider, c’est arbitrer entre un coût certain aujourd’hui et un gain incertain demain.

Idée clé

Toute décision de gestion se prend dans l’incertitude : on cherche à réduire le risque, pas à le supprimer.
