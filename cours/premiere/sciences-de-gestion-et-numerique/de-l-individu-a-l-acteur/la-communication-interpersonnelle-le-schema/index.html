La communication interpersonnelle : le schéma

Sciences de gestion et numérique · Première STMG · Thème 1 - De l’individu à l’acteur

La communication est l’échange d’informations entre des personnes. C’est elle qui fait « tenir » le collectif : sans communication, pas de coordination ni de relations. La communication interpersonnelle (entre deux individus) obéit à un schéma que l’on doit savoir décrire et repérer sur un cas.

Le schéma de la communication compte huit éléments. L’émetteur est celui qui envoie le message, et le récepteur celui qui le reçoit. Le message est l’information transmise. Le code est le système de signes commun aux deux : une langue, des symboles, un jargon. Le canal est le support du message : la voix, le téléphone, un mail, un affichage, une visioconférence.

Le feedback, ou rétroaction, est la réponse du récepteur, qui devient à son tour émetteur. Le référent est le sujet et le contexte de l’échange. Le bruit, enfin, désigne tout ce qui gêne ou déforme le message : un bruit réel, le stress, un malentendu.

Le feedback est essentiel : sans retour du récepteur, l’émetteur ne sait pas si son message a été compris. Une communication réussie est une communication où le message reçu correspond au message voulu.

Attention

Communiquer ≠ informer. Informer, c’est envoyer un message dans un seul sens (une note de service). Communiquer, c’est un échange avec du feedback : le récepteur réagit et l’émetteur ajuste.
