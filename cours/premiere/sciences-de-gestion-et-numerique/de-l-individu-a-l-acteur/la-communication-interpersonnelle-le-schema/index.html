La communication interpersonnelle : le schéma

Sciences de gestion et numérique · Première STMG · Thème 1 - De l’individu à l’acteur

Inès envoie « Passe voir Sofia, c’est urgent ! » à Théo. Il lit, ne répond rien. A-t-il compris ? Impossible à savoir… et c’est tout le problème.

La communication est l’échange d’informations entre des personnes. La communication interpersonnelle (entre deux individus) obéit à un schéma à huit éléments.

  • Émetteur : celui qui envoie le message ; récepteur : celui qui le reçoit.
  • Message : l’information transmise.
  • Code : système de signes commun (langue, symboles, jargon).
  • Canal : support du message (voix, téléphone, mail, affichage, visioconférence).
  • Feedback (rétroaction) : réponse du récepteur, qui devient émetteur.
  • Référent : sujet et contexte de l’échange.
  • Bruit : tout ce qui gêne ou déforme le message (bruit réel, stress, malentendu).

Sans feedback, l’émetteur ne sait pas si son message a été compris. La communication est réussie quand le message reçu correspond au message voulu.

Attention

Communiquer ≠ informer. Informer, c’est envoyer un message à sens unique (une note de service). Communiquer, c’est un échange avec du feedback.
