Exemple traité - une fonction Python pour les intérêts composés (boucle for)

Mathématiques · Première STMG · Chapitre 7 - Algorithmique et Python

Énoncé

On veut une fonction qui calcule le capital après n années à 3 % (intérêts composés), à partir d’un capital de départ.

Programme commenté :

def capital(depart, annees):
c = depart
for i in range(annees):
c = c * 1.03 # +3 % chaque année
return round(c, 2)

print(capital(2000, 2)) # affiche 2121.8

  • La boucle for répète l’opération `annees` fois.
  • La variable c est mise à jour à chaque tour (accumulation).
  • `round(c, 2)` arrondit à 2 décimales ; `range(n)` compte de 0 à n − 1.

Lien maths ↔ Python

Cette boucle calcule exactement une suite géométrique : Python automatise le calcul des termes.
