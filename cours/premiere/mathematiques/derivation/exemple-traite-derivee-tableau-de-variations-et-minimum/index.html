Exemple traité - dérivée, tableau de variations et minimum

Mathématiques · Première STMG · Chapitre 4 - Dérivation

Les notions clés

Dérivée
f’(x) = 4x − 8
Minimum en x = 2
f(2) = 8 − 16 + 3 = −5

Énoncé

Soit f(x) = 2x² − 8x + 3.
1) Calcule f’(x).
2) Dresse le tableau de variations.
3) Quel est le minimum de f ?

Résolution :

  • Dérivée : f’(x) = 4x − 8.
  • Signe : f’(x) = 0 ⇔ x = 2 ; f’ < 0 avant 2, f’ > 0 après → f décroît puis croît.
  • Minimum en x = 2 : f(2) = 8 − 16 + 3 = −5.

Lien

Le sommet d’une parabole correspond à f’(x) = 0 : dérivation et second degré racontent la même histoire.
