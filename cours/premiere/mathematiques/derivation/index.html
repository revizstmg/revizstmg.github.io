Chapitre 4 - Dérivation

Mathématiques · Première STMG · 3 chapitres

La dérivée mesure comment une fonction varie. C’est l’outil de l’optimisation.

L’essentiel du thème

  • f’(a) = pente de la tangente en a ; tangente : y = f’(a)(x − a) + f(a).
  • (ax² + bx + c)’ = 2ax + b.
  • f’ > 0 croissante · f’ < 0 décroissante · f’ = 0 (change de signe) → extremum.
