Le prix d’équilibre

Économie · Première STMG · Thème 5 - Les marchés sont-ils concurrentiels ?

Les notions clés

si le prix est trop haut
l’offre dépasse la demande → surplus → les prix baissent
si le prix est trop bas
la demande dépasse l’offre → pénurie → les prix montent

Le prix d’équilibre est le prix pour lequel la quantité offerte = la quantité demandée. Le marché tend naturellement vers ce prix :

  • si le prix est trop haut : l’offre dépasse la demande → surplus → les prix baissent ;
  • si le prix est trop bas : la demande dépasse l’offre → pénurie → les prix montent.

Rareté et prix

Une gelée détruit une partie de la récolte de fraises.
→ L’offre chute alors que la demande reste forte : le prix d’équilibre augmente. Le prix joue son rôle de signal (la rareté se paie plus cher).
