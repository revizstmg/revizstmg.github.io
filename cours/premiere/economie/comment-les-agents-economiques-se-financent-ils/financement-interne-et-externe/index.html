Financement interne et externe

Économie · Première STMG · Thème 4 - Comment les agents économiques se financent-ils ?

Les notions clés

le financement interne (autofinancement)
utiliser sa propre épargne, ses bénéfices mis en réserve - pas de dette, mais des moyens limités
le financement externe
trouver des fonds à l’extérieur, soit sur le marché financier (direct), soit auprès d’une banque (indirect)

Pour se financer, un agent (surtout une entreprise) a d’abord un choix de base :

  • le financement interne (autofinancement) : utiliser sa propre épargne, ses bénéfices mis en réserve - pas de dette, mais des moyens limités ;
  • le financement externe : trouver des fonds à l’extérieur, soit sur le marché financier (direct), soit auprès d’une banque (indirect).
