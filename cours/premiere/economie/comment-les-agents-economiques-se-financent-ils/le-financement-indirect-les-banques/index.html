Le financement indirect (les banques)

Économie · Première STMG · Thème 4 - Comment les agents économiques se financent-ils ?

Dans le financement indirect (ou intermédié), l’agent passe par un intermédiaire : la banque. Elle collecte l’épargne des uns et accorde des crédits aux autres, remboursés avec intérêts.

C’est le mode de financement le plus courant pour les ménages (crédit immobilier, crédit conso) et les petites entreprises, qui n’ont pas accès facilement à la Bourse.
