Le droit de propriété : usus, fructus, abusus

Droit · Première STMG · Thème 4 - Quels sont les droits reconnus aux personnes ?

Les notions clés

Usus
le droit d’utiliser le bien
Fructus
le droit d’en percevoir les revenus (ex. un loyer)
Abusus
le droit d’en disposer (vendre, détruire)

Le droit de propriété est le droit le plus complet sur un bien (qui peut être corporel - une maison, une voiture - ou incorporel - une créance, une marque). Il comporte trois attributs :

  • Usus : le droit d’utiliser le bien.
  • Fructus : le droit d’en percevoir les revenus (ex. un loyer).
  • Abusus : le droit d’en disposer (vendre, détruire).

On lui reconnaît trois caractères : absolu (le plus large possible), exclusif (le propriétaire est seul à en jouir) et perpétuel (il dure tant que le bien existe).

Attention

Ces caractères connaissent des limites : respect de l’intérêt général (expropriation, urbanisme) et du voisinage. Ainsi, un trouble anormal du voisinage (bruit, nuisances excessives) engage la responsabilité de son auteur.

Exercices corrigés

1. Que signifie : « Usus » ?

  1. le droit d’en disposer (vendre, détruire)
  2. le droit d’utiliser le bien
  3. le droit d’en percevoir les revenus (ex. un loyer)
Voir la correction

le droit d’utiliser le bien

Usus → le droit d’utiliser le bien

2. Quelle est la bonne définition de « Fructus » ?

  1. le droit d’utiliser le bien
  2. le droit d’en percevoir les revenus (ex. un loyer)
  3. le droit d’en disposer (vendre, détruire)
Voir la correction

le droit d’en percevoir les revenus (ex. un loyer)

Fructus → le droit d’en percevoir les revenus (ex. un loyer)
