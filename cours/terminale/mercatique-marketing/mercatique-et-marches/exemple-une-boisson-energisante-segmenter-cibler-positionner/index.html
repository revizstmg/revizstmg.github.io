Exemple - une boisson énergisante : segmenter, cibler, positionner

Mercatique (Marketing) · Terminale STMG · Thème 2 - Mercatique et marchés

Les notions clés

Segmentation
découper le marché (âge, mode de vie, sportifs…)
Ciblage
choisir le segment « jeunes actifs sportifs »
Positionnement
l’image voulue (« énergie naturelle et saine ») pour se distinguer des concurrents

Cas

Une marque lance une nouvelle boisson énergisante.

  • Segmentation : découper le marché (âge, mode de vie, sportifs…).
  • Ciblage : choisir le segment « jeunes actifs sportifs ».
  • Positionnement : l’image voulue (« énergie naturelle et saine ») pour se distinguer des concurrents.

3 étapes distinctes

Segmenter (découper) → cibler (choisir) → positionner (image). On ne les confond pas.

Exercices corrigés

1. Que signifie : « Segmentation » ?

  1. découper le marché (âge, mode de vie, sportifs…)
  2. l’image voulue (« énergie naturelle et saine ») pour se distinguer des concurrents
  3. choisir le segment « jeunes actifs sportifs »
Voir la correction

découper le marché (âge, mode de vie, sportifs…)

Segmentation → découper le marché (âge, mode de vie, sportifs…)

2. Quelle est la bonne définition de « Ciblage » ?

  1. l’image voulue (« énergie naturelle et saine ») pour se distinguer des concurrents
  2. choisir le segment « jeunes actifs sportifs »
  3. découper le marché (âge, mode de vie, sportifs…)
Voir la correction

choisir le segment « jeunes actifs sportifs »

Ciblage → choisir le segment « jeunes actifs sportifs »
