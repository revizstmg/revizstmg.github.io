Les sources fiables : INSEE, Eurostat, Banque de France, OCDE

Les notions clés

INSEE
statistiques françaises (PIB, chômage, prix)
Eurostat
données de l’Union européenne
Banque de France / BCE
monnaie, taux, inflation
  • INSEE : statistiques françaises (PIB, chômage, prix).
  • Eurostat : données de l’Union européenne.
  • Banque de France / BCE : monnaie, taux, inflation.
  • OCDE, FMI, Banque mondiale : comparaisons internationales.

Réflexe

Citer une source officielle et une date renforce la crédibilité. Se méfier des chiffres sans source.
