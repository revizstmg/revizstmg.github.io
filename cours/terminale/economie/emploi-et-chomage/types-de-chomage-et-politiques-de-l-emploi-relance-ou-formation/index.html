Types de chômage et politiques de l’emploi : relance ou formation

Économie · Terminale STMG · Thème 7 - Emploi et chômage

Les notions clés

Chômage conjoncturel
Ralentissement (crise) ; remède : relance
Chômage structurel
Compétences inadaptées ; remède : formation
Chômage frictionnel
Transition entre deux emplois ; normal
Politiques actives de l’emploi
Agissent sur les causes (formation, aides à l’embauche)
Politiques passives de l’emploi
Atténuent les conséquences (indemnisation)

La fermeture d’une usine jette d’un coup des centaines de personnes sur le marché du travail. Certaines retrouveront vite un poste ; d’autres, dont le métier disparaît, devront se reconvertir (formation). Le chômage n’a donc pas une seule cause.

Le chômage conjoncturel est causé par un ralentissement de l’économie, une crise ; on le combat par la relance. Le chômage structurel vient de compétences inadaptées aux emplois proposés ; on le combat par la formation. Le chômage frictionnel correspond à la transition entre deux emplois : il est normal dans une économie où les gens changent de poste.

Les politiques de l’emploi se répartissent en deux familles : actives (agir sur les causes : formation, aides à l’embauche, allègements de charges) et passives (atténuer les conséquences : indemnisation). Une bonne politique combine les deux.

Lien avec l’État

Le bon remède dépend du bon diagnostic : le chômage conjoncturel appelle une relance, le chômage structurel appelle la formation.
