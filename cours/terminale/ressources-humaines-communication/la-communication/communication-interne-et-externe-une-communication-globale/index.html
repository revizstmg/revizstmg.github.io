Communication interne et externe : une communication globale

Ressources humaines & Communication · Terminale STMG · Thème 3 - La communication

Les notions clés

Communication interne / externe
Vers les salariés / vers le public, les clients et les partenaires
Communication commerciale / institutionnelle
Pour vendre / pour valoriser l’image
Communication formelle / informelle
Officielle / spontanée (« radio couloir »)
Communication globale
Cohérence de tous les messages de l’organisation

La communication interne (vers les salariés : notes, réunions, intranet) n’a ni la même cible ni les mêmes objectifs que la communication externe (vers les clients et partenaires : publicité, site, réseaux). Confondre les deux, c’est risquer le contresens.

Trois critères permettent de classer une communication. Selon le destinataire, elle est interne, tournée vers les salariés, ou externe, tournée vers le public, les clients et les partenaires. Selon l’objet, elle est commerciale quand elle cherche à vendre, ou institutionnelle quand elle travaille l’image de l’organisation.

Selon le cadre, elle est formelle quand elle est officielle, ou informelle quand elle circule de façon spontanée, comme la « radio couloir ».

Cohérence

La communication globale vise la cohérence de tous ces messages : ce qu’on dit en interne, aux clients et au public ne doit pas se contredire.
