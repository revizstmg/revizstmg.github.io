La base de données relationnelle : tables, clés primaires et étrangères

Systèmes d’information de gestion · Terminale STMG · Thème 2 - Les bases de données et le langage SQL

Base de données relationnelle
Ensemble de tables reliées entre elles par des clés
Table
Tableau de données sur un même sujet (ex. CLIENTS)
Enregistrement
Une ligne (un client précis)
Champ
Une colonne (nom, ville…)
Clé primaire

Lien vers une autre table

Cas

Une appli musicale doit relier des millions d’utilisateurs, de titres et de playlists, et retrouver instantanément « les chansons de la playlist de Léa ».

Impossible avec un simple tableur. On utilise une base de données relationnelle : des tables (utilisateurs, titres, playlists) reliées entre elles par des clés. Chaque table a une clé primaire (un identifiant unique) ; une clé étrangère fait le lien vers une autre table. C’est ce qui évite de tout réécrire et garde les données cohérentes.

Quelques mots suffisent à décrire une base relationnelle. Une table est un tableau de données sur un même sujet, comme CLIENTS. Un enregistrement est une ligne de cette table, qui correspond à un client précis. Un champ est une colonne, qui décrit une caractéristique comme le nom ou la ville.

La clé primaire est l’identifiant unique de chaque ligne : aucune autre ligne ne peut avoir la même valeur. La clé étrangère est le lien vers une autre table : elle reprend la clé primaire de cette autre table.

À retenir

Base relationnelle = tables liées par des clés. Clé primaire = identifiant unique ; clé étrangère = lien vers une autre table.
