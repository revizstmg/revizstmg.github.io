Le modèle relationnel : clé primaire, clé étrangère, relations

Systèmes d’information de gestion · Terminale STMG · Thème 2 - Les bases de données et le langage SQL

Les notions clés

Table (relation)
Tableau de données sur un même sujet (ex. CLIENTS)
Enregistrement (ligne)
Un élément précis de la table (ex. un client)
Champ (colonne)
Une caractéristique des enregistrements (nom, ville, e-mail)
Clé primaire
Identifiant unique de chaque enregistrement (ex. id_client)
Clé étrangère
Champ qui reprend la clé primaire d’une autre table et crée le lien entre les tables

Une base de données organise et stocke l’information de façon structurée pour la retrouver facilement. Le modèle le plus répandu est le modèle relationnel : les données sont rangées dans des tables (comme des tableaux).

Le modèle relationnel a son propre vocabulaire. Une table, aussi appelée relation, est un tableau de données consacré à un seul sujet, par exemple la table CLIENTS. Chaque enregistrement, ou ligne, correspond à un élément précis de ce sujet : un client donné. Chaque champ, ou colonne, décrit une caractéristique commune à tous les enregistrements : le nom, la ville, l’adresse e-mail.

Deux champs jouent un rôle particulier. La clé primaire est l’identifiant unique de chaque enregistrement, par exemple id_client : deux lignes ne peuvent jamais avoir la même valeur. La clé étrangère est un champ d’une table qui reprend la clé primaire d’une autre table ; c’est elle qui crée le lien entre les deux.

La clé primaire identifie de façon unique chaque ligne (deux clients ne peuvent avoir le même id). La clé étrangère crée les relations entre tables : par exemple, une table COMMANDES contient l’id_client (clé étrangère) qui pointe vers la table CLIENTS. C’est ce qui évite de tout répéter.

À retenir

Base relationnelle = tables liées par des clés. Clé primaire = identifiant unique ; clé étrangère = lien vers une autre table.
