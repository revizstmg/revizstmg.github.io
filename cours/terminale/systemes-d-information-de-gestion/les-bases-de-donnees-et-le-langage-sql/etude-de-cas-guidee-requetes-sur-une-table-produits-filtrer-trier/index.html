Étude de cas guidée - requêtes sur une table PRODUITS : filtrer, trier, regrouper

Systèmes d’information de gestion · Terminale STMG · Thème 2 - Les bases de données et le langage SQL

Énoncé. Base avec une table PRODUITS(id_produit, nom, prix, categorie). Écrire les requêtes demandées.

Q1 - Produits de moins de 10 €, triés par prix

SELECT nom, prix
FROM PRODUITS
WHERE prix < 10
ORDER BY prix ASC ;

Q2 - Nombre de produits dans la catégorie « Boissons »

SELECT COUNT(*)
FROM PRODUITS
WHERE categorie = 'Boissons' ;

Q3 - Prix moyen des produits par catégorie

SELECT categorie, AVG(prix)
FROM PRODUITS
GROUP BY categorie ;

Méthode

Traduire la question en SQL : quoi afficher (SELECT), où (FROM), quelle condition (WHERE), quel tri/regroupement (ORDER BY / GROUP BY). Vérifier guillemets et point-virgule.
