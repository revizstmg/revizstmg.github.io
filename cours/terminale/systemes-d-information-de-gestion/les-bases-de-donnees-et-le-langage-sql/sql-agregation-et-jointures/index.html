SQL - agrégation et jointures

Systèmes d’information de gestion · Terminale STMG · Thème 2 - Les bases de données et le langage SQL

Les notions clés

COUNT()
Compte les lignes
SUM()
Additionne une colonne
AVG()
Calcule la moyenne d’une colonne
MAX / MIN
Donne la valeur la plus grande / la plus petite (extremum)
Jointure
Croisement de deux tables par l’égalité clé primaire = clé étrangère

Les fonctions d’agrégation résument un ensemble de lignes en un seul nombre. COUNT() sert à compter les lignes, SUM() à additionner les valeurs d’une colonne, AVG() à en calculer la moyenne, et MAX() ou MIN() à trouver la plus grande ou la plus petite valeur, c’est-à-dire un extremum.

On les combine souvent avec une condition WHERE pour ne calculer que sur certaines lignes, par exemple le total des commandes d’un seul client.

Jointure

SELECT CLIENTS.nom, COMMANDES.montant FROM CLIENTS, COMMANDES WHERE CLIENTS.id = COMMANDES.id_client ;

À retenir

Agrégation = calculer ; jointure = croiser deux tables via leur clé commune.
