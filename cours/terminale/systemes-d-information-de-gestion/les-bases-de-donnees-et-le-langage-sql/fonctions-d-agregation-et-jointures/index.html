Fonctions d’agrégation et jointures

Systèmes d’information de gestion · Terminale STMG · Thème 2 - Les bases de données et le langage SQL

Les notions clés

Fonction d’agrégation
Fonction SQL qui calcule un seul résultat à partir d’un ensemble de lignes
COUNT()
Compte le nombre de lignes
SUM()
Additionne les valeurs d’une colonne
AVG()
Calcule la moyenne d’une colonne
MAX() / MIN()
Renvoie la valeur maximale / minimale d’une colonne
Jointure
Requête qui croise plusieurs tables grâce à la clé étrangère

Le SQL permet aussi de calculer sur des ensembles de lignes grâce aux fonctions d’agrégation, et de croiser plusieurs tables avec les jointures.

Quatre fonctions d’agrégation sont à connaître. COUNT() compte le nombre de lignes qui répondent à la requête : combien de clients habitent à Paris, combien de commandes ont été passées. SUM() additionne les valeurs d’une colonne numérique, par exemple les montants pour obtenir le chiffre d’affaires total.

AVG() calcule la moyenne d’une colonne, comme le panier moyen. Enfin, MAX() et MIN() renvoient respectivement la plus grande et la plus petite valeur d’une colonne, comme la commande la plus élevée ou le prix le plus bas. Une fonction d’agrégation renvoie un seul résultat pour tout un ensemble de lignes.

Agrégation

Chiffre d’affaires total des commandes :
SELECT SUM(montant) FROM COMMANDES ;
Nombre de clients parisiens :
SELECT COUNT(*) FROM CLIENTS WHERE ville = 'Paris' ;

La jointure relie deux tables via leur clé commune pour combiner leurs informations. On précise l’égalité des clés dans le WHERE (ou avec JOIN … ON).

Jointure

Nom du client et montant de ses commandes :
SELECT CLIENTS.nom, COMMANDES.montant
FROM CLIENTS, COMMANDES
WHERE CLIENTS.id_client = COMMANDES.id_client ;

À retenir

Agrégation = calculer (COUNT, SUM, AVG…). Jointure = croiser deux tables via leur clé commune. Souvent combinées avec GROUP BY pour des totaux par catégorie.
