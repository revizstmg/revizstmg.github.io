Le langage SQL : interroger la base

Systèmes d’information de gestion · Terminale STMG · Thème 2 - Les bases de données et le langage SQL

Les notions clés

SELECT
les colonnes à afficher (SELECT = toutes)
FROM
la table concernée
WHERE
la condition de filtrage (=, <, >, AND, OR, LIKE)

Le SQL (Structured Query Language) est le langage qui permet de poser des questions à une base de données (« requêtes »). La requête de base sélectionne des colonnes, dans une table, selon une condition.

SELECT colonnes
FROM table
WHERE condition
ORDER BY colonne ;

  • SELECT : les colonnes à afficher (SELECT * = toutes).
  • FROM : la table concernée.
  • WHERE : la condition de filtrage (=, <, >, AND, OR, LIKE).
  • ORDER BY : le tri (ASC croissant, DESC décroissant).

Requête simple

Afficher le nom et la ville des clients de Paris, triés par nom :
SELECT nom, ville
FROM CLIENTS
WHERE ville = 'Paris'
ORDER BY nom ;

À retenir

Structure de base : SELECT (quoi) FROM (où) WHERE (quelle condition) ORDER BY (quel tri). Ne pas oublier le point-virgule final et les guillemets autour du texte.
