Exemple - les clients de Lyon : SELECT, WHERE, ORDER BY

Systèmes d’information de gestion · Terminale STMG · Thème 2 - Les bases de données et le langage SQL

Besoin

Table Client(id_client, nom, ville). On veut le nom des clients de Lyon, classés par ordre alphabétique.

SELECT nom
FROM Client
WHERE ville = 'Lyon'
ORDER BY nom ;

  • SELECT choisit les colonnes ; FROM la table ; WHERE filtre les lignes ; ORDER BY trie.
  • Pour compter : SELECT COUNT(*) FROM Client WHERE ville = 'Lyon' ;

Piège

WHERE filtre AVANT regroupement, HAVING filtre APRÈS un GROUP BY. Et n’oublie jamais la condition de jointure entre deux tables.
