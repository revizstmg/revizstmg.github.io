SQL - SELECT, FROM, WHERE, ORDER BY

Systèmes d’information de gestion · Terminale STMG · Thème 2 - Les bases de données et le langage SQL

SELECT colonnes FROM table WHERE condition ORDER BY colonne ;

Exemple

SELECT nom, ville FROM CLIENTS WHERE ville = 'Lyon' ORDER BY nom ;

Pièges

Guillemets autour du texte, point-virgule final, WHERE filtre avant regroupement.

À retenir

SELECT (quoi) · FROM (où) · WHERE (condition) · ORDER BY (tri).
