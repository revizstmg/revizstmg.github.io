Thème 2 - Les bases de données et le langage SQL

Systèmes d’information de gestion · Terminale STMG · 9 chapitres

Pour mémoriser durablement l’information, l’organisation utilise une base de données relationnelle, interrogée grâce au langage SQL. Savoir lire une requête est au cœur de la spécialité.

L’essentiel du thème

  • Base relationnelle = tables (lignes = enregistrements, colonnes = champs).
  • Clé primaire = identifiant unique ; clé étrangère = lien vers une autre table.
  • Requête type : SELECT colonnes FROM table WHERE condition ORDER BY champ ;
  • Fonctions de calcul : COUNT, SUM, AVG, MIN, MAX (+ GROUP BY pour regrouper).
