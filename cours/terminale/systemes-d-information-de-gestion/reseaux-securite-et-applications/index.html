Thème 4 - Réseaux, sécurité et applications

Systèmes d’information de gestion · Terminale STMG · 10 chapitres

Les informations circulent sur des réseaux. Il faut comprendre comment (client-serveur, protocoles), les protéger (confidentialité, intégrité, disponibilité) et savoir comment sont construites les applications qui les exploitent.

L’essentiel du thème

  • Architecture client-serveur : le client envoie une requête, le serveur renvoie une réponse (via TCP/IP, HTTP/HTTPS).
  • Sécurité = DICP : Disponibilité, Intégrité, Confidentialité, Preuve (traçabilité : on sait qui a fait quoi).
  • Parades : mots de passe forts, mises à jour, antivirus/pare-feu, sauvegardes, chiffrement.
  • HTML = structure, CSS = mise en forme ; une appli responsive s’adapte à la taille de l’écran.
