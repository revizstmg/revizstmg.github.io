Exercice type - sondage : un résultat non significatif

Mathématiques · Terminale STMG · Chapitre 7 - Loi normale et estimation

Énoncé. Sondage sur 625 personnes : 52 % favorables. Donner l’intervalle de confiance à 95 % et conclure.

Résolution

1/√625 = 1/25 = 0,04 → IC = [0,52 − 0,04 ; 0,52 + 0,04] = [0,48 ; 0,56].

Conclusion. L’intervalle contient 50 % : on ne peut pas affirmer que la majorité est favorable. Le résultat n’est pas significatif.

Méthode

IC = f ± 1/√n, puis interpréter : l’intervalle franchit-il un seuil clé (50 %) ?
