Interpoler, extrapoler et interpréter

Mathématiques · Terminale STMG · Chapitre 4 - Statistiques à deux variables

Les notions clés

Interpolation
estimer une valeur à l’intérieur de la plage des données observées. Généralement fiable
Extrapolation
estimer une valeur au-delà des données observées (prévoir le futur). Plus risquée : on suppose que la tendance se poursuit, ce qui n’est pas garanti

Une fois l’équation y = a x + b obtenue, on l’utilise pour estimer une valeur de y correspondant à une valeur de x. On distingue deux situations.

  • Interpolation : estimer une valeur à l’intérieur de la plage des données observées. Généralement fiable.
  • Extrapolation : estimer une valeur au-delà des données observées (prévoir le futur). Plus risquée : on suppose que la tendance se poursuit, ce qui n’est pas garanti.

Le coefficient a s’interprète concrètement : c’est la variation de y quand x augmente de 1. Le coefficient b est la valeur de y quand x = 0. Toujours donner le sens réel de ces nombres dans le contexte de l’énoncé.

Prévision

Ajustement CA = 2,5 x + 40 (x = budget pub en k€, CA en k€).
Pour x = 20 : CA ≈ 2,5 × 20 + 40 = 90 k€.
Interprétation de a = 2,5 : chaque 1 000 € de pub supplémentaire rapporte 2 500 € de CA.

Piège

L’ajustement n’est valable que si les points sont bien alignés. Extrapoler très loin (x = 1000 alors que les données vont jusqu’à 30) donne un résultat peu fiable : à signaler dans la copie.

  2. Plus risquée
  3. 90 k€
  4. peu fiable

peu fiable
