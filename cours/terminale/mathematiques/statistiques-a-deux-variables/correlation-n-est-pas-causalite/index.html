Corrélation n’est pas causalité

Mathématiques · Terminale STMG · Chapitre 4 - Statistiques à deux variables

Deux variables peuvent évoluer ensemble sans que l’une cause l’autre : c’est le piège de la corrélation ≠ causalité.

Exemple

Les ventes de glaces et les noyades augmentent l’été ensemble : la vraie cause commune est la chaleur, pas un lien direct.

À retenir

Un ajustement montre une relation statistique, pas forcément une cause. Rester prudent dans l’interprétation.
