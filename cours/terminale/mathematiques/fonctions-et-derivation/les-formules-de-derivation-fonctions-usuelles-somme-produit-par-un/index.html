Les formules de dérivation : fonctions usuelles, somme, produit par un réel

Mathématiques · Terminale STMG · Chapitre 3 - Fonctions et dérivation

Les notions clés

Dérivée d’une constante k
0
Dérivée de x
1
Dérivée de 1/x
−1/x²
Dérivée d’une somme
(u + v)′ = u′ + v′

(k·u)′ = k·u′

La dérivée f ′ se calcule avec des formules à connaître, et des règles d’opérations.

Les dérivées des fonctions usuelles se retiennent par cœur. Une constante k a pour dérivée 0, la fonction x a pour dérivée 1 et la fonction x² a pour dérivée 2x. La règle générale pour une puissance est : la dérivée de xⁿ est n·xⁿ⁻¹ ; ainsi, la dérivée de x³ est 3x² et celle de x⁴ est 4x³. Enfin, la dérivée de 1/x est −1/x² (pour x ≠ 0).

Ces formules se combinent : on dérive une somme terme à terme, et un nombre placé devant une fonction reste devant sa dérivée. Avec f(x) = 4x³ − 2x + 7, on obtient f ′(x) = 4 × 3x² − 2 × 1 + 0 = 12x² − 2.

(u + v)′ = u′ + v′ (k·u)′ = k·u′

Exemple

f(x) = 3x² − 5x + 2 → f ′(x) = 3·(2x) − 5·(1) + 0 = 6x − 5.

À retenir

On dérive terme par terme : chaque puissance descend son exposant (n·xⁿ⁻¹), une constante disparaît.

Exercices corrigés

1. Que signifie : « Dérivée d’un produit par un réel » ?

  1. −1/x²
  2. (k·u)′ = k·u′
  3. (u + v)′ = u′ + v′
  4. 1
Voir la correction

(k·u)′ = k·u′

Dérivée d’un produit par un réel → (k·u)′ = k·u′

2. À quoi correspond « Dérivée d’une somme » ?

  1. 0
  2. (u + v)′ = u′ + v′
  3. 1
  4. (k·u)′ = k·u′
Voir la correction

(u + v)′ = u′ + v′

Dérivée d’une somme → (u + v)′ = u′ + v′
