Du signe de la dérivée aux variations

Mathématiques · Terminale STMG · Chapitre 3 - Fonctions et dérivation

La dérivée est l’outil roi pour étudier les variations d’une fonction. La règle fondamentale relie le signe de f ′ au sens de variation de f.

  • Si f ′(x) > 0 sur un intervalle → f est croissante sur cet intervalle.
  • Si f ′(x) < 0 sur un intervalle → f est décroissante sur cet intervalle.
  • Si f ′(x) = 0 et que f ′ change de signe → f admet un extremum (maximum ou minimum) en ce point.

Étudier les variations, c’est donc : calculer f ′, étudier son signe, puis dresser le tableau de variations. Un maximum correspond à un passage de f ′ du positif au négatif ; un minimum, du négatif au positif.

Optimisation

f(x) = −x² + 4x (bénéfice selon la quantité x).
f ′(x) = −2x + 4. f ′(x) = 0 pour x = 2. f ′ passe de + à − → maximum en x = 2.
Bénéfice maximal : f(2) = −4 + 8 = 4.

Lien avec la gestion

La dérivée sert à optimiser : trouver la quantité qui maximise le bénéfice ou minimise le coût. On cherche là où f ′ s’annule en changeant de signe.
