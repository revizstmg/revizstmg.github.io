Lecture graphique : signe de f ′ et tangentes

Mathématiques · Terminale STMG · Chapitre 3 - Fonctions et dérivation

Sans calcul, une courbe se lit : là où elle monte, f ′ > 0 ; là où elle descend, f ′ < 0 ; à un sommet ou un creux, f ′ = 0.

Le nombre dérivé f ′(a) est le coefficient directeur de la tangente au point d’abscisse a. Une tangente horizontale ⇒ f ′(a) = 0.

À retenir

Tangente montante → f ′(a) > 0 ; horizontale → f ′(a) = 0 ; descendante → f ′(a) < 0.
