Sens de variation d’une suite : le rôle de la raison

Mathématiques · Terminale STMG · Chapitre 2 - Suites numériques

Les notions clés

Suite croissante
Chaque terme est plus grand que le précédent : uₙ₊₁ > uₙ
Suite arithmétique : sens de variation
Croissante si r > 0, décroissante si r < 0
Suite géométrique (u₀ > 0) : sens de variation
Croissante si q > 1, décroissante si 0 < q < 1

Une suite est croissante si chaque terme est plus grand que le précédent, décroissante sinon. On le détermine avec la raison.

Pour une suite arithmétique de raison r, le sens de variation se lit sur le signe de la raison. Si r > 0, on ajoute un nombre positif à chaque étape : la suite est croissante. Si r < 0, on retire quelque chose à chaque étape : la suite est décroissante. Si r = 0, tous les termes sont égaux et la suite est constante.

Pour une suite géométrique dont le premier terme est positif (u₀ > 0), on compare la raison q à 1. Si q > 1, chaque terme est plus grand que le précédent : la suite est croissante. Si 0 < q < 1, chaque terme n’est qu’une fraction du précédent : la suite est décroissante. Si q = 1, la suite est constante.

Exemple

uₙ₊₁ = uₙ + 15 (r = 15 > 0) → croissante. vₙ₊₁ = 0,9·vₙ (q = 0,9 < 1, v₀ > 0) → décroissante.

À retenir

Arithmétique : le signe de r décide. Géométrique (termes positifs) : q > 1 croît, q < 1 décroît.

Exercices corrigés

1. Que signifie : « Suite croissante » ?

  1. Chaque terme est plus grand que le précédent : uₙ₊₁ > uₙ
  2. Croissante si q > 1, décroissante si 0 < q < 1
  3. Croissante si r > 0, décroissante si r < 0
Voir la correction

Chaque terme est plus grand que le précédent : uₙ₊₁ > uₙ

Suite croissante → Chaque terme est plus grand que le précédent : uₙ₊₁ > uₙ

2. « Suite géométrique (u₀ > 0) : sens de variation » : quelle proposition est correcte ?

  1. Croissante si r > 0, décroissante si r < 0
  2. Chaque terme est plus grand que le précédent : uₙ₊₁ > uₙ
  3. Croissante si q > 1, décroissante si 0 < q < 1
Voir la correction

Croissante si q > 1, décroissante si 0 < q < 1

Suite géométrique (u₀ > 0) : sens de variation → Croissante si q > 1, décroissante si 0 < q < 1
