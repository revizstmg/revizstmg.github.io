Arithmétique ou géométrique : raison, formule et croissance

Mathématiques · Terminale STMG · Chapitre 2 - Suites numériques

Les notions clés

Suite arithmétique
On ajoute la raison r ; uₙ = u₀ + n × r ; croissance linéaire
Suite géométrique
On multiplie par la raison q ; uₙ = u₀ × qⁿ ; croissance exponentielle
Formule explicite
Formule qui donne uₙ directement en fonction de n

Les deux types de suites se comparent sur trois points. D’abord, pour passer d’un terme à l’autre, on ajoute la raison r dans une suite arithmétique, alors qu’on multiplie par la raison q dans une suite géométrique.

Ensuite, la formule explicite, qui donne directement le terme de rang n sans calculer tous les précédents, s’écrit uₙ = u₀ + n × r pour une suite arithmétique et uₙ = u₀ × qⁿ pour une suite géométrique. Enfin, la croissance est linéaire dans le premier cas, car les points de la représentation sont alignés, et exponentielle dans le second : pour q > 1, l’écart entre deux termes consécutifs grandit de plus en plus vite.
