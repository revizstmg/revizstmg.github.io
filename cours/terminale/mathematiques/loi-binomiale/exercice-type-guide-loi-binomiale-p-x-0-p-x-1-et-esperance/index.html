Exercice type guidé - loi binomiale : P(X = 0), P(X ≥ 1) et espérance

Mathématiques · Terminale STMG · Chapitre 6 - Loi binomiale

Énoncé. Une machine produit des pièces dont 5 % sont défectueuses. On prélève un échantillon de n = 20 pièces (production assez grande pour supposer l’indépendance). X = nombre de pièces défectueuses.

Étape 1 - Modéliser

Deux issues (défectueuse/conforme), n = 20 répétitions indépendantes, p = 0,05 constant → X ~ B(20 ; 0,05).

Étape 2 - Espérance

E(X) = n × p = 20 × 0,05 = 1 pièce défectueuse en moyenne par échantillon.

Étape 3 - Une probabilité (calculatrice)

P(X = 0) = 0,95²⁰ ≈ 0,358 : environ 36 % des échantillons ne contiennent aucune pièce défectueuse.
P(X ≥ 1) = 1 − P(X = 0) ≈ 1 − 0,358 = 0,642.

Méthode « binomiale »

1) Vérifier les conditions du schéma de Bernoulli et écrire X ~ B(n ; p). 2) Traduire la question (=, ≤, ≥). 3) Calculatrice pour la probabilité. 4) Donner E(X) = np si demandé et interpréter.
