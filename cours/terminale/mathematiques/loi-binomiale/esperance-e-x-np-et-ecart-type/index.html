Espérance E(X) = np et écart-type

Mathématiques · Terminale STMG · Chapitre 6 - Loi binomiale

E(X) = n·p σ(X) = √( n·p·(1 − p) )

Exemple

B(50 ; 0,5) : E(X) = 25 (nombre moyen de succès). σ = √(50×0,5×0,5) = √12,5 ≈ 3,54.

À retenir

E(X) = np est le nombre moyen de succès attendu sur un grand nombre de répétitions.
