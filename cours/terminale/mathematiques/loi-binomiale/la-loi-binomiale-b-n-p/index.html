La loi binomiale B(n ; p)

Mathématiques · Terminale STMG · Chapitre 6 - Loi binomiale

Si X compte le nombre de succès dans un schéma de Bernoulli à n épreuves de probabilité de succès p, alors X suit la loi binomiale de paramètres n et p, notée X ~ B(n ; p).

P(X = k) = C(n, k) × pᵏ × (1 − p)ⁿ⁻ᵏ pour k = 0, 1, …, n

Le coefficient C(n, k) (« combinaison de k parmi n ») compte le nombre de façons d’obtenir k succès parmi n épreuves. En STMG, on calcule P(X = k), P(X ≤ k) et P(X ≥ k) à la calculatrice (fonctions binomFdp / binomFRép).

L’espérance E(X) donne le nombre moyen de succès attendu sur un grand nombre de répétitions : c’est un résultat très intuitif et souvent demandé.

Espérance : E(X) = n × p Écart-type : σ(X) = √( n × p × (1 − p) )

Espérance

On lance 50 fois une pièce (p = 0,5). Nombre moyen de « face » : E(X) = 50 × 0,5 = 25.

Traduire les énoncés

« au moins k succès » → P(X ≥ k) = 1 − P(X ≤ k − 1). « au plus k » → P(X ≤ k). « exactement k » → P(X = k). Bien traduire est la clé.
