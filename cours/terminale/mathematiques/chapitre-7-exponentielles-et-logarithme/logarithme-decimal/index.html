Logarithme décimal

Mathématiques · Terminale STMG · Chapitre 7 : Exponentielles et logarithme

Les notions clés

Logarithme décimal
Pour b > 0, log(b) est la solution de 10ˣ=b
Logarithme d’un produit
log(ab)=log(a)+log(b), pour a,b > 0
Logarithme d’une puissance
log(aⁿ)=n log(a), pour a > 0

Pour b > 0, le logarithme décimal log(b) est l’unique réel x tel que 10ˣ=b. La fonction log est définie seulement sur les réels strictement positifs et est strictement croissante. Log(1)=0 et log(10)=1.

Pour a,b > 0 : log(ab)=log(a)+log(b), log(a/b)=log(a)−log(b) et log(aⁿ)=n log(a). Ces règles concernent les produits et quotients ; log(a+b) n’est pas log(a)+log(b).

Application corrigée

10ˣ=1 000 donne x=log(1 000)=3. Pour 10ˣ=25, x≈1,398 ; une valeur négative ou nulle ne possède pas de logarithme réel.
