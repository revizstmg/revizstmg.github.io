Fonctions exponentielles de base a

Mathématiques · Terminale STMG · Chapitre 7 : Exponentielles et logarithme

Les notions clés

Exponentielle de base a
Fonction x ↦ aˣ, définie sur ℝ pour a > 0
Puissance zéro
Pour a > 0, a⁰ = 1
Produit de puissances de même base
aˣ × aʸ = aˣ⁺ʸ

Pour a > 0, la fonction exponentielle de base a prolonge à tout réel x la suite géométrique aⁿ. On écrit f(x) = aˣ. Les valeurs de aˣ sont strictement positives ; a⁰ = 1. Une croissance composée peut ainsi être étudiée entre deux dates non entières.

Les propriétés des puissances restent valables : aˣ⁺ʸ = aˣ × aʸ, aˣ⁻ʸ = aˣ / aʸ et (aˣ)ⁿ = aⁿˣ. On ne remplace pas une somme de puissances par une puissance de somme.

Application corrigée

Un capital de 1 000 € croît de 5 % par an : C(t)=1 000×1,05ᵗ. Après 2,5 ans, C(2,5)≈1 129,73 €. Le coefficient est 1,05, pas 0,05.
