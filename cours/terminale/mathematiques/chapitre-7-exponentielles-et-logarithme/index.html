Chapitre 7 : Exponentielles et logarithme

Mathématiques · Terminale STMG · 5 chapitres

Exponentielles et logarithme décimal, programme de Terminale technologique applicable en 2026-2027.

L’essentiel du thème

  • Exponentielle : f(x)=aˣ avec a>0.
  • Logarithme décimal : inverse de la puissance de 10.
  • Seuil : résoudre puis vérifier le premier entier convenable.

Les chapitres

  1. Fonctions exponentielles de base aPour a > 0, la fonction exponentielle de base a prolonge à tout réel x la suite géométrique aⁿ. On écrit f(x) = aˣ.
  2. Variations des exponentiellesSi a > 1, aˣ est strictement croissante. Si 0 < a < 1, elle est strictement décroissante. Pour a = 1, elle est constante.
  3. Logarithme décimalPour b > 0, le logarithme décimal log(b) est l’unique réel x tel que 10ˣ=b.
  4. Résoudre une équation exponentielleAvec a > 0, a ≠ 1 et b > 0, l’équation aˣ=b donne x=log(b)/log(a).
  5. Taux moyen et duréesLe coefficient multiplicateur moyen sur n périodes est (Vf/Vi)^(1/n), pour Vi,Vf>0 et n>0.
