# Charte de l’interface

Consignes du propriétaire du 24 octobre 2026 : informations vérifiables, aplats de couleur, boutons sans forme de pilule, émojis d’origine (rétablis le 25 octobre), titres courts, pas de tiret long affiché, au maximum une animation par session et aucun badge IA promotionnel.

La transformation de présentation se fait à la compilation du JSX. Elle conserve les données, les actions, les champs saisis, les éléments React et les valeurs numériques. Les textes affichés utilisent le tiret court et conservent les émojis d’origine. Les attributs accessibles et les options natives restent en texte. Les données pédagogiques et leurs empreintes ne sont pas réécrites. Aucune observation ni mutation du DOM de React.

Les feuilles de style passent par le traitement PostCSS des surfaces ; les styles inline utilisent la même règle d’aplat. Les couleurs et variables sont conservées. Les graphiques SVG utilisent aussi des aplats. Les contrôles interactifs ont un rayon de 8 px ; photos et illustrations peuvent garder leur forme.

Les animations et transitions décoratives sont désactivées, confettis compris. Une apparition du logo de 250 ms peut être accordée une seule fois dans la session du navigateur ; elle est désactivée si le mouvement réduit est demandé ou si le stockage est indisponible. Minuteries, progression et retournement fonctionnel des cartes restent opérationnels.

L’audit des sources n’a pas trouvé de témoignages ni de compteurs de popularité inventés. Les XP, pièces, résultats, objectifs, conditions de récompense et effectifs affichés restent ceux des données existantes. Les exemples ne doivent jamais être présentés comme des utilisateurs réels. Les badges IA et l’intitulé promotionnel du tuteur sont retirés ; les informations de provenance, les limites d’une correction automatique et les accords d’envoi de données restent explicites.

Les tests de charte vérifient les pages principales, les fenêtres, les aplats, les rayons, les émojis, les tirets, l’accessibilité clair/sombre, les petits écrans et la limite d’animation. Les parcours fonctionnels utilisent des données simulées, sans écrire dans la vraie base.
