# Partager des ressources RévizSTMG

Préparation du 25 octobre 2026. Ces textes ne sont pas envoyés automatiquement. Aucun soutien d’un lycée, professeur ou partenaire n’est revendiqué.

## Choisir le bon lien

- Catalogue public : https://revizstmg.github.io/cours/
- Méthode, auteurs et sources : https://revizstmg.github.io/a-propos/
- Ressources à partager : https://revizstmg.github.io/partager/
- Langues : https://revizstmg.github.io/cours/langues/

Pour une recommandation pédagogique, préférer l’adresse de la fiche concernée à l’accueil général. Les pages peuvent être lues sans compte ni JavaScript ; les exercices interactifs s’ouvrent depuis chaque chapitre. Vérifier le contenu avant de le recommander.

## Suivi concret

Noter uniquement les échanges et liens réellement obtenus : date, page partagée, destinataire ou communauté autorisée, réponse, URL du lien publié. Une proposition d’envoi n’est pas un backlink acquis. Aucun volume de recherche ni gain de position n’a été mesuré dans cette tâche.

## Après publication

La propriété Search Console existante doit conserver l’adresse https://revizstmg.github.io/. Le nouveau sitemap.xml remplace automatiquement les anciens fichiers fixes. L’inspection d’une ou deux fiches publiques permet de demander leur exploration sans répéter les demandes. L’indexation et le classement restent des décisions des moteurs. Bing Webmaster Tools se configure dans le compte du propriétaire ; llms.txt sert de guide de lecture, sans garantie d’utilisation par un moteur.
